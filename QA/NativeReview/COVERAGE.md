## Real native journey and failure fixtures — Not executed: environment isolation blocker

The gate failed before services started in [run 36512065014](https://github.com/xxsw11/nidaa-ios-proof/actions/runs/36512065014), source `ea63b0`, evidence artifact `11009450865`: external TCP/UDP policy denial and loopback TCP checks passed, but wildcard IPv4/IPv6 bind-denial checks were false (probe exit 3). No native Auth/PostgreSQL health journey or native UI/backend end-to-end test ran. The policy was not relaxed, and automatic environment retries are disabled. These are infrastructure observations, not application failures or physical-device evidence.

Both tests are in [NativeIntegrationUITests.swift](../../UITests/NativeIntegrationUITests.swift). They use **one disposable Simulator sequentially**. Supabase Auth, PostgreSQL, mail and API are real if the environment gate succeeds; local device authentication alone is simulated and visibly labeled.

| Test | Actual UI steps / assertions encoded | Fixture boundary |
|---|---|---|
| `testRealSequentialRegistrationConsentResponseResolveRestartAndWithdrawal` | Register A and B; submit actual local-mail verification tokens; A creates targeted invitation; B explicitly opts into directional consent; A selects B, authenticates locally and separately confirms; B fetches, acknowledges, opens and responds; A observes and resolves; restart retains terminal state; B withdraws; A can no longer target B; each logout hides the previous account’s navigation/details | Test process reads Mailpit and passes tokens through native input. Invitation copying/pasting is through UI. No fixture grants consent or writes a response. This is not simultaneous multi-device reception. |
| `testRealSeparateFaultFixturesDoNotDuplicateOrReopen` | Offline refresh produces an error; reconnect/refresh does not add command POSTs or alerts; deliberately lost committed reply leaves an unknown operation; restart retains lookup; querying resolves exactly one server alert with exactly one create POST; expiry removes retry; revoked session clears account display; reauthentication does not reopen expired state | Separate authenticated loopback fixture drops a reply after commit, toggles proxy availability, ages an alert, or revokes sessions. It cannot create consent/responses. Counts are compared against baseline. |

The native disconnection scenario currently exercises **refresh without a mutation**. A never-sent offline mutation, its staleness window and reconnection suppression are covered by Swift `testNeverSentDraftAndReconnectDoNotDispatch` and `testStaleDraftRemainsNeverSentWithoutNetworkMutation`, not a dedicated real native UI scenario. Do not report that broader native scenario as executed.

`Integration/native/runtime.py` methods `setup()` / `smoke()` and [isolation_probe.py](../../Integration/native/isolation_probe.py) are a separate infrastructure gate: native process startup, actual email verification/login/logout, loopback listeners and policy-denial errors. A successful health gate alone is not either native UI test.

## Preserved local experience and remaining scope

The 17 tests in [LocalExperienceUITests.swift](../../UITests/LocalExperienceUITests.swift) remain separate regressions for the completed local simulation. Examples include `testBothActionsFailureCancellationAndRestartHaveNoAuthorization`, `testBothActionsBackgroundDuringAuthenticationAndConsentChanges`, `testExpiredAuthorizationAndTerminalRestoration`, `testStorageFailuresAreVisibleAndRetainValidData`, `testLargeTextActionReviewRemainsUsable`, and `testApplicationAndUITestStorageAreIsolated`. Native review UI changes also require actual Debug/Release builds. Neither local simulation nor a Release build substitutes for live backend execution.

Unexecuted or unimplemented gaps must remain visible: saved-credential selection; simultaneous two-Simulator reception; real native recovery/block/delete/retention journeys beyond the mapped tests; production capacity/paging and operational restore guarantees; physical Keychain, Face ID/Touch ID hardware, APNs, sound/Focus/Bluetooth/Low Power/force-quit delivery and Critical Alerts. No personal iCloud account, hosted backend, public tunnel, paid service or real notification is required or authorized by this coverage map.
