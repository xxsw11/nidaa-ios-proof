# اختبار نداء على محاكي iPhone سحابي

المستودع: https://github.com/xxsw11/nidaa-ios-proof

وافق صاحب المشروع على نشر المصدر في مستودع عام واختباره سحابيًا. يعمل الملف على مشغّل GitHub قياسي macos-15، ويتوقف إذا أصبح المستودع خاصًا. لا يحتاج Apple ID أو مفاتيح أو شهادات.

يبدأ البناء عند رفع تغييرات المصدر إلى main، أو يدويًا من Actions ثم NIDAA - iOS Simulator Proof ثم Run workflow. المهلة 20 دقيقة والاحتفاظ بالأدلة 3 أيام.

ينفذ اختبارات Python، ثم اختبارات Swift على macOS، ثم يبني التطبيق لمحاكي iPhone ويشغله ويلتقط صورة. افتح التشغيل ثم Artifacts لتنزيل السجلات والصورة. هذه شاشة الإثبات التقني وليست واجهات v06 الكاملة، والناتج ليس IPA للتثبيت على هاتف.

لا يرسل هذا التشغيل أي تنبيه. ولا يثبت صوت الهاتف أو Bluetooth أو الكشاف أو المصادقة الحيوية الفعلية أو APNs أو تجاوز الصامت. تتطلب هذه النقاط جهازًا فعليًا، وموافقة Apple اللازمة للتنبيهات الحرجة.

ملفات المستودع العام متاحة للجميع. لا ترفع Developer.xcconfig أو مفاتيح أو رموز أجهزة أو أدلة شخصية.
