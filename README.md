## العرض المحلي الأصلي المحفوظ

واجهة SwiftUI عربية RTL بهوية صفراء وسوداء، ودائرة موثوقة، وتدفق نداء محلي كامل مع تخصيص المظهر. هذه مرحلة محاكاة داخل التطبيق؛ **لا إشعارات نظام، لا APNs، لا صوت، ولا خدمة إرسال متصلة**.

بُنيت على main عند `113fc4daf93f6ee7400e08976b2bd7369ad13580` في الفرع `codex/native-local-experience`. تصميم v06 والأرشيفات محفوظة دون تعديل. المصدر السابق وسجلاته متاحة في تاريخ Git.

ابدأ بـ[دليل التجربة](Docs/LOCAL_EXPERIENCE.md)، ثم [حالة الإثبات](IOS_PROOF_STATUS.md) و[نتيجة السحابة](CLOUD_BUILD_STATUS.md). افتح `NidaaProof.xcodeproj` واختر `NidaaProof-Local` ومحاكي iPhone. لا حاجة إلى حساب Apple أو توقيع للمحاكي.

| المسار | المحتوى |
|---|---|
| App/Experience | الشاشات العربية ومنسق الجلسة والمظهر |
| App/Services | مصادقة Apple، قراءة الأذونات، وخدمات الإشعار المعطلة لهذه المرحلة |
| ProofCore | منطق الموافقات والحالات والتحقق والتفضيلات، دون SwiftUI أو شبكة |
| UITests | رحلات XCTest ولقطات محاكي حقيقية |
| QA | فحوص الحزمة، تحضير الحمولة دون إرسال، ومصفوفة الهاتف المؤجلة |
| Docs | دليل التشغيل وحدود المرحلة والخصوصية والأدلة |

لا يستخدم العرض بيانات الأسرة. الشخصيات الافتراضية خيالية، ومنها سارة، والحرف الرمزي مشتق من الاسم. جهات العرض والمظهر وخيار القفل محفوظة محليًا؛ النداءات وسجلها محفوظة بملف محلي محمي وتُستعاد بعد إعادة التشغيل دون إرسال تلقائي. الإعدادات تتيح إعادة الضبط.

المصادقة الأصلية منفصلة عن قفل التطبيق: كل إنشاء أو إعادة محاولة أو إضافة مستقبِل يحتاج تحققًا جديدًا ثم تأكيدًا صريحًا خلال 15 ثانية. انظر [دليل التثبيت المحلي](Docs/LOCAL_STABILIZATION.md). تجاوز الاختبار محصور شرطيًا في Debug Simulator ويُعلن بوضوح. لا يوجد في Release أو على iPhone فعلي.

اختبار الهاتف الفعلي **مؤجل لعدم توفر أجهزة Apple**، وليس شرطًا لإكمال هذه المرحلة. لا تعد نتائج المحاكي دليلًا على Face ID الحقيقي أو وصول التنبيهات أو تجاوز الصامت.
